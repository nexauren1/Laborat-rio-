# NoteFlow — Offline Notes

A proposed offline-first notes app built with Flutter.

## Planned features
- Create, edit, search, pin, categorize, and delete notes
- Local storage, with no account or custom backend
- Light and dark themes
- Responsive Android and web interface

## Source protection
This repository is currently public. The paid source package has **not** been uploaded here, because anyone can download code from a public repository. Before publishing the paid source to this repository, change its visibility to **Private** in **Settings → General → Danger Zone → Change repository visibility**. A private repository is only visible to people who have access, although forks made while it was public may remain public.

The app source package is being prepared separately. Do not treat this placeholder README as evidence that a build has passed or that the app is ready for store release.
