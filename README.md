# NoteFlow — Offline Notes

**A polished, offline-first Flutter notes app designed for personal use and customization.**

## Features
- Create, edit, search, pin, categorize, and delete notes
- Notes stored locally on the device; no account or backend required
- Light and dark themes
- Responsive layout prepared for Android and Flutter Web
- No runtime permissions required for the core offline-notes experience
